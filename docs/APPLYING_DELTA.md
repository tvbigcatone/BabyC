# Applicazione delta W34

Questo pacchetto è cumulativo rispetto alla baseline W33 inclusa. Contiene il report W34 e i log dell'esperimento binary32 respinto, con la baseline sorgente ripristinata.

Applicare i file del pacchetto mantenendo la struttura `babyc/`. Non aspettarsi che il probe FP architetturale passi: il difetto float/double resta aperto. La verifica riproducibile è descritta in `VERIFY.txt`.
